## Search for a source before agreeing there is none

**Law:** On a claim of "no written source" or "no source", search the docs, specs, and contracts under the root, the rulings files (the top-level `rulings.md` and the slice's), and the `rules-*.md` files you read first, before you agree: a field that the filler asks the user about must have nothing in them that answers it, and the code's own say must be unclear or contradict itself, with nothing plainly wrong in it.

**When:** Every question record, and every claim of no source.

Bad: A CONFIRMED on "no source" with the spec folder unsearched, where the spec answers the field on page one.
Good: The same field with the search done, the spec's sentence cited, and the question refused — WRONG, with the source.
