## Try to find a way the row can happen

**Law:** On a claim that "this row can't happen", try to find a way — any input, order of events, or state that reaches it — and if you find one, the claim is WRONG and the row stays open; every link of a `CantHappen` chain must carry its citation, and one missing link makes the claim WRONG, full stop.

**When:** Every `CantHappen` claim in a report.

Bad: A CONFIRMED on a chain whose third link you didn't grep, because the first two held.
Good: The same chain with a way found — the input that reaches the row — quoted, and the claim WRONG.
