## Confirm a CantHappen only with every link verified

**Law:** Grade a `CantHappen` record like any other, and first try to find a way the row can happen — any input, order of events, or state that reaches it — because a confirmed one closes its row: confirm it only when every link of the chain carries its citation and you have grepped and verified each link in the file it names; a way found makes the claim WRONG, and one missing or unverified link makes it WRONG, full stop.

**When:** Every `CantHappen` record you grade.

Bad: A CONFIRMED on a chain whose third link you didn't grep, because the first two held.
Good: The same chain with every link grepped and the CONFIRMED written on the last one — or the input that reaches the row quoted, and the claim WRONG.
