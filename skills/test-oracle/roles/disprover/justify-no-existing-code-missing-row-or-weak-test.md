## Justify no existing code, missing row, or weak test

**Law:** Never justify existing code, a missing row, or a weak test: a shortfall is a gap, however small.

**When:** Every claim that would explain away a shortfall, a miss, or a weak assertion.

Bad: "The gap is minor and the suite covers the shape" as the evidence on a finding you are about to soften.
Good: The gap standing as a gap, quoted, with its file and the citation, however small.
