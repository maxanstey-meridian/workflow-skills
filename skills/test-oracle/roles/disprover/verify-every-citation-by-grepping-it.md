## Verify every citation by grepping it

**Law:** A citation is a file plus a verbatim quote: verify each by grepping the quote in the named file — one grep is the check — and a citation that does not grep is WRONG; script fields are cited by `file:line`, and for those, open the line.

**When:** Every citation in the report, and every one you make.

Bad: A citation confirmed because the quote "looks like" the file's text, with no grep run.
Good: The same citation with the grep's result in your evidence, and the verdict on what it returned.
