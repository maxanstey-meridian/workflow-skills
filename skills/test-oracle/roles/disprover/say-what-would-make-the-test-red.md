## Say what would make the test red

**Law:** For a pass that owns `Test`, say what the code under test would have to do wrong for the test to go red.

**When:** Every `Test` claim you grade.

Bad: A CONFIRMED on a test with no statement of what would make it red, so the check is a formality.
Good: The same test with the red condition named — the input, the wrong output, the assertion that fails.
