## Say whether the row can happen

**Law:** Say whether the row can happen, only on lines you have read: that the code hides a route to a row is not enough on its own — say what hides it, and whether any other way still reaches it — and if you are not sure, the row can happen, so you write no `CantHappen`.

**When:** Every row, before you report.

Bad: No `CantHappen` written, and none explained, on a row you never opened.
Good: The row's route opened, the hiding named with its file and quote, and the verdict — can happen, or the chain — written either way.
