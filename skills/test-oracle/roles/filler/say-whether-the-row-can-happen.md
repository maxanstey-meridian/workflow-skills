## Say whether the row can happen

**Law:** Say whether every row can happen, on lines you have read: that the code hides a route to a row is not enough on its own — say what hides it, and whether any other way still reaches it — and write a `CantHappen` only where the chain holds, every link of it carrying its citation, a link without one, or resting on a file you didn't open in full, meaning you are not sure and write none.

**When:** Every row, before you report.

Bad: A `CantHappen` whose middle link is "the validator stops it", with the validator unread.
Good: The same chain quoted link by link, every link opened in full — and where a link will not open, no `CantHappen`, and the row left able to happen.
