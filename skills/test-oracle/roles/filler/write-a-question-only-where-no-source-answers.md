## Write a question only where no source answers

**Default:** Invent no intent: an expected value is a quoted source with its `Source` word, and where none of the five answers the field, and the code's own say is unclear or contradicts itself, write a question for the user with one recommended answer — never an intent you supplied yourself.

**When:** A field you cannot fill as a value.

Bad: A question on a field a doc under the root answers, because the doc was easier to skip than to read; "the product surely wants the list sorted by date" on a field no source says to sort.
Good: The doc read and cited where it answers, and a question with the one recommended answer only where the code's own say contradicts itself.
