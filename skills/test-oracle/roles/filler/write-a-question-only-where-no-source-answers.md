## Write a question only where no source answers

**Default:** A question is for the user, with one recommended answer, and you write it where no source in the source order says what the field should hold, and the code's own say is unclear or contradicts itself, or where only the user can rule.

**When:** A field you cannot fill as a value.

Bad: A question on a field a doc under the root answers, because the doc was easier to skip than to read.
Good: The same field read, with its value and the doc cited, and the question saved for the field where the code's own say contradicts itself.
