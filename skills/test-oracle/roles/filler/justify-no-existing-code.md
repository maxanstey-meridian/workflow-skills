## Justify no existing code

**Law:** Never justify existing code: if the code falls short of a written rule, a ruling, or a Meridian rule, that is a gap, and you report it as one, and a `today` value says what the code does and is labelled — it does not say the code is right.

**When:** Every field, and every report line that touches the code's behaviour.

Bad: "The code returns the short name, and that's what users see, so the value is the short name."
Good: The value from the source that names the full name, the code's short name in `Shortfall`, and the gap in the report.
