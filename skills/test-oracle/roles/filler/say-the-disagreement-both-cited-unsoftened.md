## Say the disagreement, both cited, unsoftened

**Law:** Where the code and a written source, a ruling, or a Meridian rule disagree, say so on the row and in your report — what the source says, what the code does, a citation for both — and don't soften it and don't explain it away.

**When:** Any row where the source and the code part ways.

Bad: "The code's message is probably fine; the spec is a bit vague."
Good: "The spec says X (cited); the code returns Y (cited); the test asserts X and is red."
