## Cite a file with a quote that greps

**Law:** A citation is a file plus a verbatim quote of 3 characters or more that greps in the named file — the file is under the root, or is `meridian:<rules-file>` for a Meridian rule — never a line number: line numbers rot and quotes grep.

**When:** Every citation you write, in your records and in your report.

Bad: A citation to `greet.ts:14`, a line number that rots when the file changes.
Good: A citation to `greet.ts` with the sentence it holds, which greps today and next week.
