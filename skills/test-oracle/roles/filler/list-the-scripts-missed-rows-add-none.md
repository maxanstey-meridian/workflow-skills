## List the script's missed rows, add none

**Law:** A thing in what the rows are read from that should be a row, that no row holds, and that the row script's stderr does not name as left out, is a defect in the script, a finding for the user: don't add a row for it — list it, with what it is read from, and the file and the quote that shows it.

**When:** Your read of what the rows are read from, for your slice.

Bad: A new row the filler wrote for the miss, so the table grows by hand.
Good: The miss in the report's Defects in the script list, with the file and the quote, and the table untouched.
