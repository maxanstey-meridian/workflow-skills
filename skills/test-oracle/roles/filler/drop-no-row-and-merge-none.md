## Drop no row and merge none

**Law:** Never drop or merge a row: a row can't happen only as the `CantHappen` bar says — another test covering it, its looking minor, and its being hard to test are not reasons.

**When:** Any row you would rather not fill.

Bad: Two rows "merged" into one fill record because they look alike.
Good: Two records, one per row, each with its own citation, the likeness noted nowhere because it changes nothing.
