## Keep a value to the outcome it expects

**Default:** A value states the expected outcome only: the input is the row's own fields, the source is the value's `Source` word and its citations, and the order a source beat is none of the value's business.

**When:** Every value a filler writes.

Bad: `today: the code returns a Result of exit 0 and out the greeting when the greet command carries a person; no written source, ruling, Meridian rule, or judgement names a different expectation.`
Good: `run returns { exit: 0, out: "Hello, Ada!" }`, with `Source: today` and the code line cited.
