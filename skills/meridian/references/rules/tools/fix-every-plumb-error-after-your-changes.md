## Fix every Plumb error after your changes

**Tooling:** Where Plumb applies, run it after completing changes, fix every `error` finding unprompted, and for each `warn` finding fix it or state the exception that applies.

**When:** A repo that uses Plumb, after you complete changes.

Bad: three Plumb errors listed as "pre-existing" when reporting the work.
Good: the three errors fixed, and one `warn` finding answered with the exception that applies.
