## Scaffold a new workspace with rivet-ts

**Tooling:** Start a new TypeScript workspace with rivet-ts's `scaffold` command.

**When:** Starting a new TypeScript project.

Bad: a workspace assembled by hand from an old repo's files.
Good: `scaffold` run first, then the result edited.

Links: [rivet-ts getting started](https://maxanstey-meridian.github.io/rivet-ts/getting-started)
