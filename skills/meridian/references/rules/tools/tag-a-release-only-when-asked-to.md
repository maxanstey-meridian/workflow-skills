## Tag a release only when asked to

**Tooling:** Create a release tag only when you are asked to; never tag unprompted.

**When:** Finishing work on a release, or any time you might create a tag.

Bad: a `v1.4.0` tag created at the end of the work, though no one asked for it.
Good: the version number worked out from the commits, and no tag created until someone asks for it.
