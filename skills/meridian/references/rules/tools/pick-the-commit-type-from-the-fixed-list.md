## Pick the commit type from the fixed list

**Tooling:** The type is one of `feat` (new behaviour or capability), `fix` (a correction to behaviour), `docs`, `refactor`, `test`, `build` (the build, dependencies, generated output), or `chore`.

**When:** Every commit message.

Bad: `update(orders): refund the shipping fee on a cancelled order`
Good: `fix(orders): refund the shipping fee on a cancelled order`
