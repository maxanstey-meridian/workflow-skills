## Use help text for the user's next question

**Default:** Supporting text explains a material consequence or answers the user's likely next question; it never restates the label.

**When:** Help and supporting text under any control.

Bad: Label "Do not overwrite the existing file" with the help text "The file will not be overwritten."
Good: The same label with the help text "The export will fail and the existing SharePoint file will remain unchanged."
